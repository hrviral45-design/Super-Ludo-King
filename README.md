# Super Ludo King

Mobile-friendly Ludo starter project. This first version includes offline pass-and-play for 2–4 players, dice rolling, token movement, captures, safe squares, home lanes and win detection.

## Run
`npm install` then `npm run dev`

## Build
`npm run build`

## Android setup
`npx cap add android` then `npx cap sync android`

Online multiplayer is a later phase and is not included in this first ZIP; it requires a realtime backend.
